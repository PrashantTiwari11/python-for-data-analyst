COMPUTER MEMORY :- WHEN A PROGRAM RUNS COMPUTER STORES THEIR DATA INTO RAM(MEMORY) .

VARIABLE :- VARIABLE IS A NAME GIVEN TO A MEMORY LOCATION .

NOTE :- IN PROGRAMMING “ = ” MEANS ‘ASSIGNMENT OPERATOR’ i.e. LEFT VARIABLE STORE RIGHT VALUE .
EXAMPLE :- X = 10
THAT MEANS NOT X = 10 !!!
THAT MEANS STORE 10 INSIDE X .

VARIABLE NAMING RULES :- 
VARIABLE CAN START WITH ALPHABET.
IT CAN BE START WITH UNDERSCORE. 
VARIABLE CAN’T BE START FROM NUMBER.
SPECIAL CHARACTERS IS NOT ALLOWED IN VARIABLES.
SPACE IS ALSO NOT ALLOWED IN VARIABLE .
VARIABLE IS CASE SENSITIVE.

IDENTIFIRES :- IDENTIFIERS ARE THE NAMES USED TO IDENTIFY VARIABLES , FUNCTIONS , CLASSES ETC.

KEYWORDS :- KEYWORDS ARE RESERVED WORDS WE CAN’T MAKE THEM VARIABLES .
EXAMPLE :- IF , ELSE , ELSE IF , FOR , WHILE ETC .

LITERALS : - LITERAL MEANS ACTUAL VALUES .
EX - AGE = 20 | VARIABLE → AGE | LITERAL → 20

ISINSTANCE() :- THIS FUNCTION IS USED TO CHECK THAT THE GIVEN OBJECT’S TYPE IS PARTICULAR OR NOT .
EX- AGE = 20
PRINT(ISINSTANCE(AGE,INT))
OUTPUT :- TRUE

TRIPLE DOUBLE QUOTES - “””PRASHANT

BASIC BUILT-IN STRING FUNCTIONS : 
split() :- 
SPLIT FUNCTION IS USED TO CONVERT STRING INTO LIST .

join() :- 
JOIN FUNCTION IS USED TO CONVERT LIST INTO STRING.

isalpha() :- 
CHECK THAT THE GIVEN STRING IS CONSIST ONLY ALPHABET OR NOT .

isdigit() :- 
CHECK THAT THE GIVEN INPUT IS CONSIDER ONLY DIGITS .

isalnum() :- 
CHECK THAT THE GIVEN STRING IS CONSIDER LETTERS + NUMBERS .
NOTE :- IF SPACE IS BETWEEN LETTERS AND NUMBERS IT WILL RETURN FALSE .

islower() :- 
CHECK THAT THE GIVEN STRING IS CONSIDER ONLY LOWERCASE LETTERS .

isuppeer() :-  CHECK THAT THE GIVEN STRING IS CONSIDER ONLY UPPERCASE LETTERS .
isspace() :- 
GIVEN INPUT CONSIDERS SPACE OR NOT .

istitle() :- 
CHECK THAT THE GIVEN STRING IS IN THE FORM OF TITLE. 

casefold() :- 
ADVANCE VERSION OF lower() .
IT IS BETTER FOR UNICODE TEXT.

LIST IS AN ORDERED , MUTABLE COLLECTION OF MULTIPLE ITEMS .

LIST vs STRING :- 
LIST MUTABLE WHILE STRING IS IMMUTABLE
STRING IS COLLECTION OF CHARACTERS WHILE LIST IS COLLECTION OF ANY OBJECTS
STRING WROTE INSIDE THE QUOTES “” WHILE LIST IS WRITTEN INSIDE SQUARE BRACKET [] 
 
                →← LIST METHODS →← 
APPEND () :- IT ADD AN ELEMENT IN THE LIST AT END .
EX:- fruits = ["Apple", "Banana"]
fruits.append("Orange")
print(fruits)
Output:
['Apple', 'Banana', 'Orange']

EXTEND () :- IT ADDS MULTIPLE ELEMENTS IN LIST AT END .
EX:- fruits = ["Apple", "Banana"]
fruits.extend(["Orange", "Mango"])
print(fruits)
Output : 
['Apple', 'Banana', 'Orange', 'Mango']

INSERT () :- INSERT DATA AT ANY POSITION.
SYNTAX : - list.insert(index,value)
EX:- fruits = [“Apple”, “Orange”]
fruits.insert(1, “Banana”)
Print (fruits)
Output :- 
['Apple', 'Banana', 'Orange']

REMOVE () :- IT DELETE VALUES .
EX:- fruits = ["Apple","Banana","Orange"]
fruits.remove("Banana")
print(fruits)
OUTPUT :- 
['Apple', 'Orange'] 

POP () :- IT DELETE ON THE BASIS OF INDEX.
EX:- 
numbers = [10,20,30]
numbers.pop(1)
print(numbers)
OUTPUT :- 
[10,30]
